# Jay-R Unite Tabunan — IT Portfolio Starter

A responsive, single-page personal IT portfolio built with HTML, CSS, and vanilla JavaScript. It is intended as a starting point for a professional website that can showcase a resume, technical skills, project case studies, systems, and contact information.

## Files

- `index.html` — page content and structure
- `styles.css` — responsive styling and visual design
- `script.js` — mobile navigation and automatic copyright year
- `assets/` — add your final resume PDF and approved portfolio media here

## Important: personalize before publishing

This starter intentionally contains prompts and draft descriptions. Before making the site public:

1. Confirm the exact number of years of experience you want to display.
2. Add your employer name, employment dates, previous roles, and verified job responsibilities.
3. Add your school name and graduation year.
4. Review every skill and remove any tool or capability you cannot confidently discuss.
5. Replace each project slot with a real project you contributed to. Explain your role, tools, problem, solution, and verified outcome.
6. Add approved screenshots, demo videos, or sanitized sample files. Do not publish employer source code, customer data, account details, internal URLs, credentials, confidential reports, or proprietary business rules.
7. Add a professional email and LinkedIn URL. Consider using a dedicated professional email address.
8. Add your final PDF resume at `assets/Jay-R-Unite-Tabunan-Resume.pdf` and add a download link in the Resume section of `index.html`.
9. Test the site on desktop and mobile before sharing it with employers.

## Preview locally

Double-click `index.html` to open it in a browser. For a local development server, open a terminal in this folder and run:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Publish with GitHub Pages

1. Create or sign in to a GitHub account.
2. Create a **public** repository named `YOUR-USERNAME.github.io` (GitHub Free supports Pages for public repositories).
3. Upload the contents of this folder to the repository root. `index.html` must be at the root.
4. Open the repository's **Settings → Pages**.
5. Under the build and deployment settings, choose deployment from the `main` branch and the `/ (root)` folder, then save.
6. Wait for the Pages deployment to finish, then open `https://YOUR-USERNAME.github.io`.
7. A custom domain is optional; you can add one later in the Pages settings and configure its DNS records with your domain provider.

Official instructions: https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site

## Notes

- This is a static website. It does not contain a server, database, login system, or backend API.
- A live interactive system demo may need separate application hosting and a secure backend. For now, showcase such systems with approved screenshots, a short demo video, sanitized sample data, or a public read-only demo environment.
- Never expose private credentials, environment files, connection strings, or workplace data in a public repository.
