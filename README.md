## Upload to GitHub
1. Open https://github.com/jayrtabunan/jayrtabunan.github.io
2. In the repository root, choose Add file > Upload files.
3. Upload `index.html`, `styles.css`, and `script.js` from this folder.
4. Upload the `Jay-R-Unite-Tabunan-Resume.pdf` file into the existing `assets` folder. If `assets` does not exist, create it by uploading the PDF with the path `assets/Jay-R-Unite-Tabunan-Resume.pdf` (GitHub's web upload interface may require creating the folder first).
5. Commit the changes to the `main` branch.
6. Wait for GitHub Pages to deploy, then refresh https://jayrtabunan.github.io/
